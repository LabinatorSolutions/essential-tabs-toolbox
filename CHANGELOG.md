# Changelog

All notable changes to Essential Tabs Toolbox are documented here.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-06

### Added

- Toolbar popup: open a pasted list of links (in the background, loaded on click, skipping links already open).
- Tab list with All, Pinned and Not pinned filters, and a By site view with one-click Copy per site.
- Clean copies: known tracking parameters are removed from every copied link.
- Sort A→Z by URL, inside each tab group, with pinned tabs and group positions unchanged.
- Close duplicates (off by default): the newly opened tab stays and the older copy closes; pinned, playing,
  sharing and grouped tabs are never closed; YouTube videos match by video.
- Recently closed: Firefox's recently closed tabs, restorable with one click.
- Requires Firefox 159 or newer (desktop).
